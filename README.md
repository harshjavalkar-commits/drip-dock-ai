# DripDock Style

Build a production-quality Progressive Web App called DripDock.

DripDock is an AI-powered wardrobe intelligence platform and personal stylist.

It should NOT feel like a simple clothing catalog.

Primary goal:

Help users dress better using clothes they already own.

Technology:

- React

- TypeScript

- Tailwind CSS

- Supabase Authentication

- Supabase PostgreSQL

- Supabase Storage

Design style:

- Apple-inspired

- Notion-inspired

- COS / Uniqlo aesthetic

- Minimal luxury

- Large whitespace

- Rounded cards

- Smooth animations

- Mobile-first

- Responsive

- iPhone PWA ready

Authentication:

- Reset Password

- Edit Profile
